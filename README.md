# 考古罗盘（Archaeology Compass）

探索遗迹时，带上一枚考古罗盘，寻找附近仍藏着战利品的可疑沙子和可疑沙砾。

## 功能

- 指向附近最近的有效考古目标。
- 目标被刷空、挖掉或离开扫描范围后，自动重新寻找。
- 找不到目标时，指针持续旋转。
- 放在物品栏中即可生效，不需要一直拿在手里。
- 按住 **Shift** 查看扫描范围和当前搜索状态。
- 只搜索已加载的区块，不会为寻找目标加载远处区域。
- 扫描范围和更新频率可由服务器调整。

它寻找的是考古方块，而不是远处的遗迹建筑。默认水平扫描范围为 **64 格**，上下各 **32 格**。

## 外观

原创 **32×32 铜制罗盘**，采用接近原版指南针的斜视外观。V2 使用两行铜制侧壁和一行暗色收边，兼顾厚度感与轻巧感。浅金色长针指向目标，绿色短尾用于区分方向。

## 合成

需要 **两把刷子、两个铜锭和一个指南针**，在工作台中按以下方式摆放：

| | | |
| :---: | :---: | :---: |
| | 刷子 | |
| 铜锭 | 指南针 | 铜锭 |
| | 刷子 | |

获得刷子或指南针后即可解锁配方书中的配方。安装对应版本的 JEI 后，也可查看合成配方；JEI 不是必需的。

## 下载与安装

前往 [Releases 下载页面](https://github.com/luanma114/archaeology-compass/releases)，选择与你的游戏版本匹配的 JAR，放入 `mods` 文件夹。

- **Minecraft：1.21.1**
- **NeoForge：21.1.235 及以上的 1.21.1 兼容版本**
- **Java：21**

单人游戏安装到客户端；多人游戏需要客户端和服务器都安装。

当前版本为 **v0.1.2 预发布**，采用 V2 折中铜壳外观，并同步项目图标。定位、配方和指针逻辑与 0.1.1 保持一致；V2 游戏内外观、干净实例安装、独立服务器联机、JEI 及性能仍需专项验证。更新内容和已知限制见对应 Release 说明。

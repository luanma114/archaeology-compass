## 后续补拍的技术要求

- 格式 PNG，分辨率不低于 1920×1080，不做缩放后再压缩
- **不得包含**：调试渲染叠加层（F3 的绿色结构框、光照/区块边界等）、鼠标 tooltip 遮挡主体、聊天栏内容、未完成的指令输入
- HUD 可以保留（快捷栏能体现物品栏中有罗盘这一特性）
- 主体物件不得被屏幕边缘裁切
- 不使用假截图、不使用美术预览冒充游戏截图

**已知现象（非缺陷，原版一致行为）**：合成**结果槽**中的罗盘指针固定朝上，不随目标变化。原因是结果槽渲染时拿不到 holder 实体，`ArchaeologyCompassPropertyFunction.unclampedCall` 走 `entity1 == null` 分支返回 `0.0F`（即第 0 帧）。原版指南针在结果槽中表现相同，无需修复；验收时按此预期判定。

**非模组渲染元素**：截图 2 中的绿色方块叠加层来自原版调试渲染器（结构／POI 一类），模组除物品模型属性外不含任何世界渲染代码。拍摄对外用图前需关闭。

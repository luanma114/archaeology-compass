# 目标方块判定规则

考古罗盘**不使用方块标签**判定目标。是否需要数据包、是否需要配置，都不需要——规则是内建的。

## 判定条件

一个方块会被当作考古目标，当且仅当同时满足：

1. 它的方块实体是 `net.minecraft.world.level.block.entity.BrushableBlockEntity` **或它的子类**
2. 它的方块实体保存数据中含 `LootTable` **或** `item` 键

第 2 条的含义：`LootTable` 表示尚未刷扫，`item` 表示刷过一次但物品还没完全刷出。两者都不存在说明方块已刷空，模组会跳过它。

> NBT 键是 `LootTable`（首字母大写），不是小写蛇形 `loot_table`。

## 这意味着什么

- **纯原版环境**：原版只有 `minecraft:suspicious_sand` 和 `minecraft:suspicious_gravel` 两个刷扫方块，所以行为就是"只找可疑沙子和可疑沙砾"。
- **整合包 / 第三方模组**：任何自定义考古方块，只要是 `BrushableBlockEntity` 的子类，**开箱即用**，无需数据包或配置。
- **不会误判**：仅名字相似、却不使用原版刷扫机制的方块不会被识别。

## 实例：All the Mods 10 的古城考古

ATM10 通过 Just Enough Archaeology 与 Allthemodium 配合，在**远古城市**里加入了考古内容。这些方块不是原版可疑沙子：

| 方块 | 方块类 | 方块实体类 |
| --- | --- | --- |
| `allthemodium:suspicious_clay` | `ATMBrushableBlock extends BrushableBlock` | `ATMBrushableBlockEntity extends BrushableBlockEntity` |
| `allthemodium:suspicious_soul_sand` | 同上 | 同上 |

因为方块实体是 `BrushableBlockEntity` 的子类，`0.1.3` 起**不需要任何额外操作**即可被罗盘找到。

> `0.1.2` 及更早版本要求方块额外属于 `archaeologycompass:archaeology_targets` 标签，因此在这个场景下必须自己写数据包。该标签已在 `0.1.3` 移除。

## 如何确认某个方块符不符合条件

游戏内对着目标方块执行：

```
/data get block <x> <y> <z>
```

- 输出里出现 `LootTable` 或 `item` → 满足第 2 条
- 输出里两者都没有 → 方块已刷空，被跳过是正确行为

至于第 1 条，只有看模组源码才能确定方块实体类型；不过实践中，凡是能被刷子正常刷扫的方块，通常都是 `BrushableBlockEntity` 的子类——**能被刷子刷 = 能被罗盘找到**，这条经验法则基本成立。

# Archaeology Compass v0.1.4 — prerelease

An artwork adjustment for **Minecraft 1.21.1 / NeoForge 21.1.235 / Java 21**.

## Changes since v0.1.3

- **Redrew the item sprite at 16×16.** The compass now shares the pixel density of the vanilla compass and of every other modded compass in All the Mods 10 (Deeper Darker, Explorer's Compass, Nature's Compass, AllTheTweaks, Twilight Forest, Applied Energistics 2 all draw at 16×16). The previous 32×32 sprite was crushed to 16 px whenever the GUI drew it at scale 1, which lost the needle entirely and made the item read as a different fidelity class next to its neighbours.
- The 16 px budget keeps the two-tone copper shell, the dark teal dial, and the pale-gold needle with its teal tail. The second side-wall row, the eight dial ticks and the patina dots are gone — at 16 px they were sub-pixel noise.
- The 400×400 project icon and the in-game mod list logo were regenerated from the new sprite.
- Target scanning, needle behaviour, networking, crafting, and configuration values are unchanged from 0.1.3.

The colour scheme was deliberately kept: Nature's Compass ships a wood-and-leaf compass, a palette further from vanilla than this one, and it still sits naturally in a vanilla inventory. Pixel density, not hue, was what made the old sprite feel out of place.

## Installation

Download the attached `archaeologycompass-0.1.4.jar` and place it in the instance's `mods` folder.

- Minecraft **1.21.1**
- NeoForge **21.1.235** minimum; any newer loader must also be compatible with Minecraft 1.21.1 and has not been separately verified.
- Java **21**
- Single-player: install on the client. Multiplayer: the server and all joining clients need the mod.
- This file is **NeoForge only**, not Forge or Fabric. JEI is optional, not required.

The compass finds nearby blocks that still hold archaeology loot. It is not a long-range structure locator. Default search range is 64 blocks horizontally and 32 above/below, with an update every 20 game ticks. Searches only loaded chunks.

## Validation and known limitations

This is a **prerelease**, not a stable-release claim.

**Validated** in a development client on a newly created world:

- Crafting the compass, and the recipe unlocking in the recipe book.
- The needle pointing at the nearest valid target while the item sits in the inventory.
- The Shift tooltip, including its "target found" state and the server's scan range.
- The 16×16 artwork loading with no missing-texture or atlas errors.

**Also validated:** the release JAR was installed into an **All the Mods 10** instance (520 mods) and the compass located naturally generated Allthemodium archaeology blocks in an Ancient City. Those blocks — `allthemodium:suspicious_clay` and `allthemodium:suspicious_soul_sand` — are not vanilla suspicious sand or gravel, so this confirms the detection rule reaches third-party archaeology blocks that a modpack injects into vanilla structures.

**Not verified, and no claim is made about it:** installation into a clean instance with no other content mods, dedicated-server multiplayer, JEI display, and performance with large scan ranges or high player counts.

**Known limitations:**

- Ordinary target/inventory changes are reflected on the next scan, not instantly.
- A block that looks like archaeology but does not use the vanilla brushing mechanic will not be found.
- Each candidate block entity in range is serialized once per scan to read its loot state. Brushable blocks are rare in practice, but a pack that places them in very large numbers will increase scanning work.

Please [report issues](https://github.com/luanma114/archaeology-compass/issues) with Minecraft, NeoForge and mod versions, reproduction steps, and relevant logs with private information removed.

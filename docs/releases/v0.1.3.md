# Archaeology Compass v0.1.3 — prerelease

A compatibility update for **Minecraft 1.21.1 / NeoForge 21.1.235 / Java 21**.

## Changes since v0.1.2

- **Target detection no longer uses a block tag.** Any block whose block entity is a Minecraft `BrushableBlockEntity` or a subclass, and whose saved data still contains `LootTable` or `item`, is treated as a target.
- **Custom archaeology blocks now work out of the box.** Modpacks no longer need a data pack to register their blocks. For example, Allthemodium's `suspicious_clay` and `suspicious_soul_sand`, which appear in Ancient Cities in All the Mods 10, are found with no extra configuration.
- Removed the `archaeologycompass:archaeology_targets` block tag and the matching `ARCHAEOLOGY_TARGETS` field.
- Target scanning, needle behaviour, networking, crafting, configuration values, and the mod list logo are unchanged.

In vanilla the behaviour is identical to 0.1.2: the only two blocks in the game that use the brushing mechanic are suspicious sand and suspicious gravel.

## Installation

Download the attached `archaeologycompass-0.1.3.jar` and place it in the instance's `mods` folder.

- Minecraft **1.21.1**
- NeoForge **21.1.235** minimum; any newer loader must also be compatible with Minecraft 1.21.1 and has not been separately verified.
- Java **21**
- Single-player: install on the client. Multiplayer: the server and all joining clients need the mod.
- This file is **NeoForge only**, not Forge or Fabric. JEI is optional, not required.

The compass finds nearby blocks that still hold archaeology loot. It is not a long-range structure locator. Default search range is 64 blocks horizontally and 32 above/below, with an update every 20 game ticks. Searches only loaded chunks.

## Validation and known limitations

This is a **prerelease**, not a stable-release claim.

**Validated** in a development client on a newly created world:

- Crafting the compass, and the recipe unlocking in the recipe book.
- The needle pointing at the nearest valid target while the item sits in the inventory. A vanilla compass in the adjacent hotbar slot pointed a different way, which shows the needle tracks the archaeology target rather than a fixed frame.
- The Shift tooltip, including its "target found" state and the server's scan range.
- The V2 artwork in game.

**Also validated:** the release JAR was installed into an **All the Mods 10** instance (520 mods) and the compass located naturally generated Allthemodium archaeology blocks in an Ancient City. Those blocks — `allthemodium:suspicious_clay` and `allthemodium:suspicious_soul_sand` — are not vanilla suspicious sand or gravel, so this confirms the new detection rule reaches third-party archaeology blocks that a modpack injects into vanilla structures.

**Not verified, and no claim is made about it:** installation into a clean instance with no other content mods, dedicated-server multiplayer, JEI display, and performance with large scan ranges or high player counts.

**Known limitations:**

- Ordinary target/inventory changes are reflected on the next scan, not instantly.
- A block that looks like archaeology but does not use the vanilla brushing mechanic will not be found.
- Each candidate block entity in range is serialized once per scan to read its loot state. Brushable blocks are rare in practice, but a pack that places them in very large numbers will increase scanning work.

Please [report issues](https://github.com/luanma114/archaeology-compass/issues) with Minecraft, NeoForge and mod versions, reproduction steps, and relevant logs with private information removed.

## 中文说明

**v0.1.3 为兼容性更新预发布**，适用于 Minecraft 1.21.1、NeoForge 21.1.235 和 Java 21。

- **目标判定不再依赖方块标签。** 只要方块实体是 `BrushableBlockEntity` 或其子类，且保存数据中仍有 `LootTable` 或 `item`，就会被当作考古目标。
- **整合包的自定义考古方块开箱即用**，不再需要写数据包。例如 All the Mods 10 中出现在远古城市的 `allthemodium:suspicious_clay` 和 `suspicious_soul_sand`，无需任何额外配置即可被找到。
- 移除了 `archaeologycompass:archaeology_targets` 方块标签及对应的 `ARCHAEOLOGY_TARGETS` 字段。
- 扫描逻辑、指针行为、网络同步、配方、配置项与模组列表图标均未改动。

纯原版环境下行为与 0.1.2 完全一致——游戏里使用刷扫机制的方块本来就只有可疑沙子和可疑沙砾两种。

**已在新建存档的开发客户端中确认**：合成与配方书解锁；物品栏中的指针指向最近有效目标；Shift 提示（含「已发现考古目标」状态与服务端范围）；V2 游戏内外观。

**另已验证**：发布 JAR 装入 **All the Mods 10**（520 个模组）实例后，罗盘在远古城市中成功定位到自然生成的 Allthemodium 考古方块。这些方块——`allthemodium:suspicious_clay` 和 `allthemodium:suspicious_soul_sand`——不是原版可疑沙子或可疑沙砾，因此这条记录证实了新的判定规则能够覆盖整合包注入到原版结构里的第三方考古方块。

**本次未验证、不作任何相关声明**：在无其他内容模组的干净实例中的安装、独立服务器多人联机、JEI 展示，以及大范围扫描与多人场景下的性能。

下载附件 `archaeologycompass-0.1.3.jar`，放入实例的 `mods` 文件夹。多人游戏需客户端与服务器都安装；此文件不支持 Forge 或 Fabric。
